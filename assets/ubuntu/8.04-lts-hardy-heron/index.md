Ubuntu 8.04 LTS Hardy Heron is the 8th release and the 2nd LTS release of the
Ubuntu distribution, developed by Canonical Ltd. Hardy Heron brought multiple
new apps, including Brasero for disk burning, Transmission for BitTorrent,
Vinagre for VNC (Virtual Network Computing) and Microsoft Active Directory
login. It also featured automatic grabbing and releasing of the mouse cursor
when running on a VMware virtual machine, and an easier method to remove Ubuntu.

+++

Ubuntu 8.04 was the first version of Ubuntu to include the Wubi installer on the
Live CD. It allowed Ubuntu to be installed as a folder within Windows and
removing the need for a disk partition.

## Features

Ubuntu 8.04 introduced a number of new applications which add features to the
desktop experience.

### New software

#### Transmission

Transmission is a free and open-source cross-platform BitTorrent client. It was
included in Ubuntu 8.04 due to its reliability and simplicity of usage.

#### Brasero

Brasero is a CD/DVD-burning application with many features, especially burning
audio and data discs, copying them and burning images to discs.

#### Vinagre

Vinagre is an open source VNC, SSH, RDP, and SPICE client for GNOME. It was
included by default with GNOME 2.22.

#### PulseAudio

PulseAudio is a free and open source sound server for Unix and Unix-like
systems, mainly Linux but also with ports to other platforms. Ubuntu 8.04
included version 0.9.6 of the sound server.

On release, there were many issues with the audio system, particularly that
PulseAudio slowed GStreamer video playback to an extremely low
speed–"practically a slideshow" as Ryan Paul on
[ArsTechnica](https://arstechnica.com/information-technology/2008/05/hardy-heron-review/)
remarked, and the exclusion of PulseAudio configuration utilities.

### Wubi installer

Ubuntu 8.04 is the first version to include Wubi, an installer that allows
Ubuntu and Windows to be on the same partition. It removes the need for
partitioning but shows up in the bootloader menu as if Ubuntu was installed on a
partition.

### Core

#### Linux kernel 2.6.24

2.6.24 includes CPU "group scheduling", memory fragmentation avoidance, tickless
support for x86-64/ppc and other architectures, many new wireless drivers and a
new wireless configuration interface, SPI/SDIO MMC support, USB authorization,
per-device dirty memory thresholds, support for PID and network namespaces,
support for static probe markers, SELinux performance improvements, SATA link
power management and port multiplier support, Large Receive Offload in network
devices, memory hot-remove support, a new framework for controlling the idle
processor power management, CIFS ACLs support, many new drivers and many other
features and fixes.

More information can be found at <https://kernelnewbies.org/Linux_2_6_24>.

#### GNOME 2.22

GNOME 2.22, released on March 12, 2008, introduced the following:

- A new photo-taking app called Cheese
- The addition of window compositing
- Transition from GNOME-VFS to GVFS networked filesystem
- Improved DVD playback and digital television support
- Built-in internationalisation in the clock
- Updates to the Evolution client
- Remote desktop viewer
- Simplified keyboard settings
- Improvements to accessibility

The release notes can be found at <https://release.gnome.org/2-22/>.

## Kubuntu 8.04

Kubuntu is a flavor of the Ubuntu distribution. Its main feature is that it
replaces GNOME with KDE.

Kubuntu 8.04 brought about two versions of KDE, KDE 3.5.9 (default) and KDE
4.0.3. KDE 4.0.3 could be installed using the KDE 4 Remix CD or using
`apt-get install kubuntu-kde4-desktop`.

More information about the improvements found in Kubuntu 8.04 can be found at
the
[Web Archive of the Kubuntu 8.04 announcement](https://web.archive.org/web/20080820222031/http://www.kubuntu.org/news/8.04-release).

## Xubuntu 8.04

Xubuntu is an Ubuntu variant that replaces GNOME with the Xfce desktop
environment and some default applications with lighter alternatives.

Xubuntu 8.04 brought about version 4.4.2 of the Xfce desktop environment,
featuring various bug fixes and slight improvements to components. More
information about Xubuntu 8.04 can be found on the
[Web Archive for Xubuntu 8.04's announcment](https://web.archive.org/web/20080728233102/http://www.xubuntu.org/news/hardy/release).

## Edubuntu 8.04

Edubuntu is a variant of the Ubuntu distribution aimed at educational
environments. Edubuntu was restructured as Ubuntu Education Edition in 8.04. The
process of installing it changed from a separate install CD to an addon for the
standard Ubuntu desktop. A user installing Ubuntu Education Edition could either
install the full environment as a single process or just some selected
applications.

The release article can be found on the
[Wayback Archive](https://web.archive.org/web/20080429185824/http://www.edubuntu.org/news/8.04-release)
of the Edubuntu website.

## Ubuntu Studio 8.04

Ubuntu Studio is a flavor of the Ubuntu distribution that bundles Ubuntu with
multiple creative work programs like GIMP, Inkscape, etc.

Ubuntu Studio first debuted alongside other variants of the 8.04 line, and came
with a real-time kernel, which was essential for quick playback in audio and
video work.

<!--https://opensource.com/article/19/8/linux-kernel-top-5-innovations-->

The page at the time can be found on the
[Web Archive](https://web.archive.org/web/20080516030329/http://ubuntustudio.org/).

## Mythbuntu 8.04

Mythbuntu is an Ubuntu deriavative built to set up a MythTV system. MythTV is a
free and open-source digital video recorder and media center application.

Mythbuntu uses the Xfce4 desktop, removing applications unnecessary for a media
center including Evolution, OpenOffice and the full GNOME desktop. A user can
choose to install the full `ubuntu-desktop`, `kubuntu-desktop`, or
`xubuntu-desktop` from the Mythbuntu Control Center. The Mythbuntu Control
Center provides a GUI to configure the system.

The website for Mythbuntu 8.04 can be found on the
[Internet Archive](https://web.archive.org/web/20080526102010/http://www.mythbuntu.org/).
